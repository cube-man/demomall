# 02 · 技术选型（§1.2）

> 状态：**已确认**（用户拍板，2026-09-30）
> 输入：[01-需求说明](01-需求说明.md) 的关键约束

## 选型结果

| 维度 | 选择 | 理由（对应约束） |
|---|---|---|
| 语言 | **Java 8** | 用户指定；推测为对齐其工作环境的主流栈；单人+AI 下 AI 对该版本熟练度极高 |
| 框架 | **Spring Boot 2.7.18** | Boot 3.x 要求 Java 17+，与 Java 8 不兼容，故锁 2.7 线的最后一个补丁版；生态成熟，AI 熟练度极高 |
| 构建 | **Maven** | 本机已就绪（工作区有现成配置与使用约定） |
| 数据存储 | **暂不引入** | 最简载体用不上；迭代需要时首选 H2（零安装，符合"本机运行即可"） |
| 版本控制 / CI | **git + GitHub Actions** | 用户此前已确认（CI 推送后生效，本地以脚本门禁先行） |
| 部署方式 | **本机运行** | 约束"本机运行即可"，不部署 |

## 否决的备选

| 备选 | 否决理由 |
|---|---|
| Java 17 + Spring Boot 3.x（AI 原推荐） | 被用户否决：指定 Java 8。代价如实记录——Boot 2.7 已停 OSS 维护、生态渐老；对流程载体无实际影响 |
| Python + FastAPI | 本机环境未验证，§1.4 需先装环境；与用户既有经验重叠少 |
| Node.js + Express | 同上 |

## 风险与待验证（移交 §1.4 环境检查）

- 本机是否装有独立 JDK 8 **待查**。
- 构建方案：有 JDK 8 则直编；没有则用已装 JDK 17 以 `--release 8` 交叉编译（字节码 8 可在 JDK 17 上编译与运行）。
- 内网/代理对 Maven 中央仓库的可达性（工作区已有备用 `maven-settings.xml` 可复用）。
